\# CSC Resource Management System — Codebase Architecture &amp; File Reference Guide This reference guide provides a map of the application's file architecture. Use this guide to quickly locate the appropriate file when addressing specific functionality, bug reports, or feature enhancements. --- ## 🧭 Topic &amp; Feature Quick Reference \* \*\*For questions about system entry, layout assembly, or SPA tab rendering:\*\* Refer to \`index.php\`. \* \*\*For questions about the sign-in screen UI or login form layout:\*\* Refer to \`login.php\`. \* \*\*For questions about authentication, credential checking, hashing, or logout logic:\*\* Refer to \`actions/auth\_action.php\`. \* \*\*For questions about database connection setup (PDO) or MySQL/SQLite settings:\*\* Refer to \`config/db.php\`. \* \*\*For questions about user sessions, access control guards, or flash alerts (\`$\_SESSION['alert']\`):\*\* Refer to \`config/session.php\`. \* \*\*For questions about custom ID generation (e.g., \`TXN-001\`, \`ITM-005\`):\*\* Refer to \`config/helpers.php\`. \* \*\*For questions about checking out equipment, processing returns, or stock updates:\*\* Refer to \`actions/txn\_action.php\`. \* \*\*For questions about inventory management (adding, editing, or archiving equipment):\*\* Refer to \`actions/item\_action.php\`. \* \*\*For questions about borrower profiles (students/organizations):\*\* Refer to \`actions/borrower\_action.php\`. \* \*\*For questions about user management (Council Admin managing committee accounts):\*\* Refer to \`actions/user\_action.php\`. \* \*\*For questions about profile updates or password changes:\*\* Refer to \`actions/profile\_action.php\`. \* \*\*For questions about printable equipment gate passes/slips:\*\* Refer to \`print\_receipt.php\`. \* \*\*For questions about client-side JS, dynamic AJAX searches, or modal triggers:\*\* Refer to \`assets/js/app.js\`. \* \*\*For questions about custom CSS styling or print constraints:\*\* Refer to \`assets/css/style.css\`. \* \*\*For questions about database tables, foreign keys, or initial schema design:\*\* Refer to \`database/confed\_borrowing.sql\`. --- ## 📁 Detailed Directory &amp; File Breakdown ### 🏠 Root Core Files \* \*\*\`index.php\`\*\* \* \*\*Role:\*\* Master Assembler &amp; Front Controller \* \*\*Description:\*\* Loads configurations, executes initial SQL queries to hydrate views, and stitches together layout chrome (\`header\`, \`topbar\`, \`sidebar\`) with SPA page fragments (\`views/pages/\`) and modals (\`views/modals/\`). Also triggers pop-up receipts when transactions are completed. \* \*\*\`login.php\`\*\* \* \*\*Role:\*\* Officer Authentication Portal View \* \*\*Description:\*\* Isolated login interface for desk officers. Displays error flash messages, blocks already-authenticated users from re-accessing sign-in, and provides demo quick-fill buttons for testing. \* \*\*\`print\_receipt.php\`\*\* \* \*\*Role:\*\* Printable Gate Pass Generator \* \*\*Description:\*\* Fetches transaction, item, borrower, and staff metadata via SQL joins to render a formatted physical gate pass formatted for receipt printing (\`window.print()\`). --- ### ⚙️ Configuration Files (\`config/\`) \* \*\*\`config/db.php\`\*\* \* \*\*Role:\*\* Database Connector &amp; Session Kickstarter \* \*\*Description:\*\* Initializes PDO MySQL/SQLite connections with exception error handling and UTF-8 encoding, while ensuring \`session\_start()\` is safely invoked. \* \*\*\`config/session.php\`\*\* \* \*\*Role:\*\* Session State &amp; Authentication Guard \* \*\*Description:\*\* Evaluates \`$\_SESSION['userID']\`, extracts user profile data and roles (\`$currentUser\`, \`$isAdmin\`), enforces redirect guards (\`header('Location: login.php'); exit;\`) for unauthenticated traffic, and manages single-use flash alerts. \* \*\*\`config/helpers.php\`\*\* \* \*\*Role:\*\* Utility &amp; ID Formatting Library \* \*\*Description:\*\* Contains global helper functions, primarily \`generate\_id()\`, which queries database tables to auto-increment formatted string keys (e.g., \`USR-001\`, \`ITM-002\`, \`TXN-005\`). --- ### ⚡ Backend Processors &amp; Action Controllers (\`actions/\`) \* \*\*\`actions/auth\_action.php\`\*\* \* \*\*Role:\*\* Authentication &amp; Session Mutator \* \*\*Description:\*\* Validates user login credentials against Bcrypt hashes (\`password\_verify\`), sets session keys upon success, handles bad attempt alerts, and destroys sessions upon logout. \* \*\*\`actions/txn\_action.php\`\*\* \* \*\*Role:\*\* Lending &amp; Return Lifecycle Controller \* \*\*Description:\*\* Handles borrowing checkouts, quantity validation, stock decrementing (\`UPDATE item\`), borrower profile creation, transaction ledger inserts (\`borrow\_transaction\`), return processing (\`return\_transaction\`), and stock restorations. \* \*\*\`actions/item\_action.php\`\*\* \* \*\*Role:\*\* Inventory Management Controller \* \*\*Description:\*\* Handles equipment CRUD operations—adding new inventory items, updating rates or descriptions, and soft-archiving (\`is\_archived = 1\`) items. \* \*\*\`actions/borrower\_action.php\`\*\* \* \*\*Role:\*\* Borrower Directory Controller \* \*\*Description:\*\* Handles creation, modification, and soft-archiving of student and campus organization borrower records. \* \*\*\`actions/user\_action.php\`\*\* \* \*\*Role:\*\* Staff Account Management Controller \* \*\*Description:\*\* Restricted to Council Administrators. Handles registering new council/committee members, updating roles, resetting passwords, and soft-deleting staff accounts. \* \*\*\`actions/profile\_action.php\`\*\* \* \*\*Role:\*\* Account Personalization Controller \* \*\*Description:\*\* Allows the currently authenticated desk officer to update their name, email, contact details, and account password. --- ### 🎨 UI Presentation Components (\`views/\`) #### Layout Shell (\`views/layout/\`) \* \*\*\`header.php\`\*\*: Standard HTML \`\` tag, meta attributes, Bootstrap CSS, and global stylesheet imports. \* \*\*\`topbar.php\`\*\*: Top navigation banner containing system branding and quick-action shortcuts. \* \*\*\`sidebar.php\`\*\*: Navigation menu bar featuring the logged-in officer badge, role indicators, and Bootstrap tab trigger buttons. \* \*\*\`footer.php\`\*\*: Closing HTML tags and script imports (\`Bootstrap JS\`, \`assets/js/app.js\`). #### Dashboard Page Tabs (\`views/pages/\`) \* \*\*\`transactions.php\`\*\*: Active lending ledger tab showing borrows and returns status tables. \* \*\*\`inventory.php\`\*\*: Item catalog tab displaying equipment descriptions, available stock, rates, and management controls. \* \*\*\`borrowers.php\`\*\*: Directory tab for searching and managing registered student/organization borrowers. \* \*\*\`purchases.php\`\*\*: Equipment restocking ledger tab for logging purchases and official receipts. \* \*\*\`reports.php\`\*\*: Multi-category report tab with date filtering and print actions. \* \*\*\`users.php\`\*\*: Admin-exclusive staff management tab for handling system user accounts. \* \*\*\`profile.php\`\*\*: Personal account view for updating active user settings. #### Modal Dialog Forms (\`views/modals/\`) \* \*\*\`modal\_txn.php\`\*\*: Interactive popup form for processing checkouts and returns with dynamic borrower search. \* \*\*\`modal\_item.php\`\*\*: Form dialog for adding or editing equipment inventory details. \* \*\*\`modal\_borrower.php\`\*\*: Form dialog for adding or editing borrower directory entries. \* \*\*\`modal\_user.php\`\*\*: Admin form dialog for registering and editing council/committee staff accounts. --- ### 📦 Static Assets (\`assets/\`) \* \*\*\`assets/js/app.js\`\*\* \* \*\*Role:\*\* Client-Side Interactivity Engine \* \*\*Description:\*\* Handles live AJAX borrower searches, dynamic subtab navigation, modal field population, and UI interaction handlers. \* \*\*\`assets/css/style.css\`\*\* \* \*\*Role:\*\* Application Stylesheet \* \*\*Description:\*\* Provides custom styling extensions, responsive layout media queries, badge colors, and print media rules (\`@media print\`). --- ### 🗄️ Database Schemas (\`database/\`) \* \*\*\`database/confed\_borrowing.sql\`\*\* \* \*\*Role:\*\* MySQL Database Schema Script \* \*\*Description:\*\* Contains \`CREATE TABLE\` definitions for \`user\`, \`item\`, \`borrower\`, \`borrow\_transaction\`, \`return\_transaction\`, and \`purchase\_transaction\` tables, along with foreign key constraints and default admin seed data.
